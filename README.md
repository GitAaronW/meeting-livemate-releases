# Meeting LiveMate / 听会台 — Downloads

Public program updates for macOS 13 and later. This repository contains release assets only; it has no API keys, meeting data, personal settings, or source repository history.

[Download the current app](https://github.com/GitAaronW/meeting-livemate-releases/releases/latest)

After installing the current app, use **Check for updates / 检查更新** in the app. Updates replace program files and keep existing AI keys, model choices, and meeting records. No GitHub login is required for public program updates. Older installations pointing at a private repository need this installer once.

Family preconfigured installers are distributed separately and remain private. They are never uploaded here. The source repository remains private.

The app is currently ad-hoc signed, not Apple notarized. macOS may require confirmation on first open. Native recording permissions must be granted on the actual Mac.
